## 5. SN74LVC245A backside placement

U1 and U2 are through-hole PDIP-20 devices installed on the back/component side of the carrier.

Locations:

```python
U1_C = (28.0, 24.0)
U2_C = (80.0, 24.0)

DIP_ROW = 7.62
DIP_PITCH = 2.54
```

The footprints must account for being installed from the backside.

When viewing the copper side:

* Pin 1 is at the lower-left.
* Pins 1–10 run upward along the left column.
* Pin 11 is at the upper-right.
* Pins 11–20 run downward along the right column.
* Pin 20 is at the lower-right.

Generate the coordinates with:

```python
def dip_backside(cx, cy):
    xl = cx - DIP_ROW / 2
    xr = cx + DIP_ROW / 2
    top = cy + 9 * DIP_PITCH / 2
    bottom = cy - 9 * DIP_PITCH / 2

    pins = {}

    for pin in range(1, 11):
        pins[pin] = (xl, bottom + (pin - 1) * DIP_PITCH)

    for pin in range(11, 21):
        pins[pin] = (xr, top - (pin - 11) * DIP_PITCH)

    return pins
```

On the physical back/component side, the notch of each IC must face the bottom edge of the board.

Add visible reference markers for pin 1.

### SN74LVC245A electrical connections

For both U1 and U2:

* Pin 1, DIR: connect to the local 1.8 V rail.
* Pins 2–9, A1–A8: connect to the common local trigger input.
* Pin 10, GND: connect to local ground using an insulated component-side over-trace jumper.
* Pins 11–13, B8–B6: unused. Retain physical holes but do not create copper pads.
* Pins 14–18, B5–B1: connect to the five output connectors through individual 68 Ω resistors.
* Pin 19, `/OE`: connect to local ground using an insulated component-side over-trace jumper.
* Pin 20, VCC: connect to the local regulated 1.8 V rail.

Use copper pads on pins 1–10 and 14–20. Pins 11–13 receive holes only.

